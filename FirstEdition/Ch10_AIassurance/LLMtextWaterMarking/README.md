## Idea and Code




# LLM Text Watermarking

## 1. Introduction

Large Language Models (LLMs) generate text by predicting the probability of the next token.

**Text watermarking** introduces a hidden statistical pattern into the generated text by slightly modifying token-selection probabilities.

The goal is to distinguish text generated by a watermarked model from ordinary text.

Unlike an image watermark, there is no visible symbol or signature.

## 2. Basic Idea

Suppose an LLM has six possible words:

| Word | Original probability |
|---|---:|
| cat | 0.30 |
| dog | 0.25 |
| bird | 0.20 |
| fish | 0.10 |
| horse | 0.10 |
| mouse | 0.05 |

The probabilities sum to 1.

We divide the vocabulary into two groups:

- Green list: cat, bird, horse
- Red list: dog, fish, mouse

The watermarking algorithm increases the probability of selecting green-list words.

For example, we multiply their original probabilities by 2, then normalize so the probabilities sum to 1 again.

| Word | Original | Watermarked |
|---|---:|---:|
| cat | 0.30 | 0.3750 |
| dog | 0.25 | 0.1563 |
| bird | 0.20 | 0.2500 |
| fish | 0.10 | 0.0625 |
| horse | 0.10 | 0.1250 |
| mouse | 0.05 | 0.0313 |

Green words become more likely, but they are not guaranteed to appear.

## 3. Python Example

Run in Google Colab or any Python environment with NumPy installed.

```python
import numpy as np

np.random.seed(42)

# Vocabulary and original probabilities
words = ["cat", "dog", "bird", "fish", "horse", "mouse"]
probs = np.array([0.30, 0.25, 0.20, 0.10, 0.10, 0.05])

# Secret green list (fixed for this simple demonstration)
green = {"cat", "bird", "horse"}

# Watermark: boost probabilities of green words
wm_probs = np.array([
    p * 2 if w in green else p
    for w, p in zip(words, probs)
])
wm_probs /= wm_probs.sum()

# Generate 100 tokens
normal = np.random.choice(words, 100, p=probs)
watermarked = np.random.choice(words, 100, p=wm_probs)

# Count green tokens
def detect(tokens):
    count = sum(w in green for w in tokens)
    return count, count / len(tokens)

print("Original probabilities:", probs)
print("Watermarked probabilities:", wm_probs)

print("\nNormal:", detect(normal))
print("Watermarked:", detect(watermarked))
```

## 4. Understanding the Code

The most important lines are:

```python
normal      = np.random.choice(words, 100, p=probs)
watermarked = np.random.choice(words, 100, p=wm_probs)
```

The parameter `p` specifies the probability of selecting each word.

- Normal generation uses the original probabilities.
- Watermarked generation uses the modified probabilities.

The watermark is introduced during token selection, not after the text has been generated.

## 5. Detecting the Watermark

The function `detect()` counts how many generated tokens belong to the green list.

For our example:

- Original probability of selecting a green token = 0.60
- Watermarked probability of selecting a green token = 0.75

Therefore, out of 100 generated tokens, we expect approximately:

| Generator | Expected green tokens |
|---|---:|
| Normal | 60 |
| Watermarked | 75 |

Actual results vary because token selection is random.

A higher green-token frequency provides evidence of watermarking.

However, this simple frequency comparison is not sufficient for reliable detection. A real detector uses a statistical test and accounts for the expected green-token frequency.

## 6. Simple Mathematics

### Original probabilities

The sum of all probabilities must equal 1:

$$
\sum_i p_i = 1
$$

### Watermarked probabilities

Multiply green-token probabilities by a factor of 2:

$$
w_i = 2p_i \quad \text{(green tokens)}
$$

For red tokens:

$$
w_i = p_i
$$

Normalize the probabilities:

$$
p'_i = \frac{w_i}{\sum_j w_j}
$$

Example for the word cat:

$$
p'(cat) = \frac{2(0.30)}{1.60} = 0.375
$$

The probability of cat increases from 30% to 37.5%.

## 7. How Real LLM Watermarking Works

Our example uses a fixed green list.

Real watermarking algorithms, such as the method proposed by Kirchenbauer et al. (2023), are more sophisticated:

1. The LLM predicts probabilities for the next token.
2. A secret key and preceding tokens determine a pseudorandom green list.
3. Green-token probabilities are increased.
4. The LLM samples the next token.
5. The process repeats for every generated token.
6. A detector reconstructs the green lists and performs a statistical test.

The watermark is therefore distributed across many tokens.

## 8. Limitations

- Short texts may not contain enough evidence.
- Editing or paraphrasing can weaken a watermark.
- False positives are possible.
- Not all AI-generated text is watermarked.
- Watermark detection is statistical evidence, not absolute proof.

```


import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

words = ["cat", "dog", "bird", "fish", "horse", "mouse"]
probs = np.array([0.30, 0.25, 0.20, 0.10, 0.10, 0.05])

green = {"cat", "bird", "horse"}

# Boost green-token probabilities
wm_probs = np.array([
    p * 2 if w in green else p
    for w, p in zip(words, probs)
])
wm_probs /= wm_probs.sum()

# Expected green probability without watermark
p_green = sum(p for w, p in zip(words, probs) if w in green)

def z_score(tokens):
    n = len(tokens)
    G = sum(w in green for w in tokens)

    return (G - n * p_green) / np.sqrt(n * p_green * (1 - p_green))

# Compare three scenarios
token_counts = [100, 1000, 10000]
normal_z = []
watermarked_z = []

for n in token_counts:

    normal = np.random.choice(words, n, p=probs)
    watermarked = np.random.choice(words, n, p=wm_probs)

    zn = z_score(normal)
    zw = z_score(watermarked)

    normal_z.append(zn)
    watermarked_z.append(zw)

    print(f"\nNumber of tokens: {n}")
    print(f"Normal:      Z = {zn:.2f}")
    print(f"Watermarked: Z = {zw:.2f}")

# Plot the results
plt.figure(figsize=(9, 5))

plt.plot(token_counts, normal_z, 'o-', label="Normal")
plt.plot(token_counts, watermarked_z, 's-', label="Watermarked")

plt.axhline(0, color='gray', linestyle='--', linewidth=1)

plt.xlabel("Number of Tokens")
plt.ylabel("Z-score")
plt.title("LLM Watermark Detection: Z-score vs. Text Length")
plt.legend()
plt.grid(True)
plt.xscale("log")
plt.xticks(token_counts, ["100", "1,000", "10,000"])

plt.show()



```
